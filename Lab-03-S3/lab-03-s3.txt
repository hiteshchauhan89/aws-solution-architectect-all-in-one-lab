# Lab 03 - Create an Amazon S3 Bucket

This lab demonstrates how to create an Amazon S3 bucket, upload objects, and configure public access for educational purposes.

---

## 1. Create an S3 Bucket

### 1.1
From the AWS Management Console, navigate to the **Amazon S3** service.

### 1.2
Click **Create Bucket**.

### 1.3
Enter a **Bucket Name** and select the **AWS Region** where the bucket will be created.

> **Note:** Bucket names must be **globally unique** across all AWS accounts.



### 1.4
You have the option to copy settings from an existing bucket.

For this lab, leave this option blank and continue.

### 1.5
In the **Configure Options** section, you can configure:

- Bucket Versioning
- Server Access Logging
- Tags
- Object-Level Logging
- Default Encryption

For this lab, keep the default settings and click **Next**.



### 1.6
In the **Set Permissions** section, configure access permissions for the bucket and its objects.

By default, **Block all public access** is enabled, which is the AWS recommended security best practice.

Review the configuration in the **Review** section.



### 1.7
Review all settings and click **Create Bucket**.

Your new S3 bucket will appear in the bucket list.



---

## 2. Upload an Object

### 2.1
Open the newly created bucket.

Click **Upload**.

### 2.2
Click **Add Files** and select one or more files to upload.



### 2.3
In the **Set Permissions** section, you can configure access permissions for the uploaded object.

For this lab, keep the default settings and click **Next**.



### 2.4
In the **Set Properties** section, you can configure:

- Storage Class
- Encryption
- Tags

Keep the **Storage Class** set to **Standard** (default), then click **Next**.



### 2.5
In the **Review** section, verify all settings.

Click **Upload**.


---

## 3. Access the Uploaded Object

### 3.1
After the upload is complete, the object will appear inside the bucket.

Click on the uploaded object.

### 3.2
On the object details page, you can view:

- Object information
- Metadata
- Object URL

Copy the **Object URL** and paste it into your web browser.

### 3.3
Because the object is stored in a **private bucket**, you will receive an **Access Denied** message.

### 3.4
To allow public access for testing purposes, return to the bucket.

Open the **Permissions** tab.

By default, **Block all public access** is enabled.

Uncheck **Block all public access**, then click **Save Changes**.

AWS will ask you to confirm this action.

> **Note:** According to AWS security best practices, S3 buckets should remain private. Public access is enabled here **only for educational purposes**.



### 3.5
After disabling public access, return to the uploaded object.

Click **Make Public**.

### 3.6
Copy the Object URL again and open it in your browser.

This time, the object will be publicly accessible.

---

- Create an Amazon S3 bucket
- Configure bucket settings
- Upload files to Amazon S3
- Configure object permissions
- Understand S3 private and public access
- Enable public access for testing purposes
- Access an uploaded object using its public URL
